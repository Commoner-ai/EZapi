# Public EZapi distribution repository

Publish only consumer guides, API signatures, schemas, consumer examples and automation helpers here. Framework implementation, internal tests, build projects and private Git history must never be copied into this repository. Keep the original EZapi repository private. Release binaries must pass the local source-free package gate before uploading.

The .cs and .csproj files under src/EZapi.Sample and docs/examples are consumer examples, not framework implementation. Full binary SDKs are release assets; the GitHub-generated source archives contain only this distribution material.
