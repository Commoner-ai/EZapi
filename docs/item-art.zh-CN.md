# 物品美术：贴近原版画风

希望新物品贴近 Probably Stolen 原版画风时，使用随开发文档提供的[原版物品美术参考](art-reference/README.md)。它是可选美术参考，不是物品注册或加载的前置条件。玩家游戏包不携带这些资料。

## 最快用法

1. 从下表选择目标物品的同类参考图，不用一次上传所有类别。
2. 把该分类图，或 `art-reference/enlarged-4x/` 中2—3张同类透明单图交给生成图片的AI。
3. 复制[中文提示词模板](art-reference/AI-PROMPT.zh-CN.txt)，填写物品结构、材质、目标逻辑尺寸。
4. AI完成后，在目标小尺寸检查轮廓、像素网格、透明背景、细节密度和与参考图的协调程度。
5. 将自己的新图绑定给物品；JSON包看[内容包](content-packs.zh-CN.md)，DLL看[Sprite资源](sprite-assets.zh-CN.md)。

## 给AI的规则

- 同类原版参考优先：匹配其像素颗粒、视角、轮廓、明暗、配色和细节密度；不要只说游戏名让AI猜画风。
- 新物品应按自己的结构定义重新设计。不要把分类图文字、棋盘格、标签或界面绘进成品。
- 用统一逻辑像素网格和清楚的成组色块，避免大图密集纹理缩小后糊成一片。
- 输出真实透明PNG，不把画出来的棋盘格当作透明通道。
- 本套液体叠层只用于液体表现，不能当成完整瓶子外壳；角色和UI不套用物品精灵规范。

## 16px、占格与导出

本套96张Sprite的宽高都是16的倍数，可把16px作为常规物品每格绘图的起点。例如按这一基准，宽2格、高3格的目标画布为32×48px。但本套图像尺寸不证明对应原生物品的实际占格；实际占格必须独立声明和核对。特殊素材可能有例外。

**16的倍数不自动保证清晰。** 按最终逻辑分辨率设计，有限细节；需要放大时使用整数倍最近邻，例如32×48 → 128×192。直接把高细节512×512插画缩小，即使目标是16的倍数也可能损失结构。大图里的不规则“假像素”不能靠一次最近邻缩小自动修复。

`originals/`保留源Sprite尺寸、画布边距和Alpha；`enlarged-4x/`每个源像素精确对应4×4方块。部分源图透明区域Alpha为1而非0，未擅自重绘；制作新图时应检查透明边缘。PNG像素尺寸、物品真实形状、Sprite轴心和运行时采样是不同设置，分别核对。EZapi没有新增“必须16的倍数”的加载限制。
