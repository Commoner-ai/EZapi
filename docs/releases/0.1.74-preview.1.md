# EZapi 0.1.74-preview.1 — 王尔德人脉网络滚动布局

人脉网络条目增加时不再向外撑大窗口。左侧保留原生详情和解锁操作，右侧提供动态分类、名称/ID 搜索、筛选及始终可见的竖向滚动条。

- 自动发现原生分类行中追加的 NetworkElement 和新分类，不硬编码原版条目名单。
- 修正卡片悬停/点击动画与网格 pivot 的坐标冲突，以及滚动条滑块越界。
- 保留原按钮回调、费用、前置条件、冷却、试玩版锁和保存路径；关闭窗口恢复布局。
- 可选开发者面板增加临时滚动压力检查，关闭窗口清除 UI 副本。
- 离线搜索/筛选/大量条目边界检查纳入原有 UI 测试组；自动进入游戏脚本按指定版本检查初始化日志。

运行程序集升级为 **0.1.74**。用户已确认卡片悬停/点击、详情、现有黑客条目和常驻竖向滚动条正常。全框架、其他 Mod 组合和保存重载的完整实机验收仍待完成；不继承旧 DLL 证据。准确范围与哈希以 [当前状态](../release-status.json) 为准。

Runtime 0.1.74 adds the Wild network browser, preserves native cards/callbacks, and restores layout at close. Scoped user UI feedback does not establish full native acceptance. Players still install one DLL; source is MIT and the developer package retains optional original-style art references with separate rights.
