# EZapi 0.1.74-preview.2 — 可选原版 Tooltip 规范与开发工具

本次更新开发文档、消费方示例和离线工具，运行程序集仍为 **0.1.74**，与 preview.1 的 DLL 完全相同。已安装 preview.1 的玩家无需替换 DLL；Mod 作者下载新版开发包获取资料。

- 新增[可选原版 Tooltip 规范](../tooltip-style.zh-CN.md)、[English guide](../tooltip-style.en.md)和[机器索引](../tooltip-style.index.json)，区分原版风格与扩展信息风格。
- 原版风格显式使用原生说明字段并关闭来源；分类、估值与真实属性保留游戏渲染。操作简介与风味叙述分开，避免重复名称或数值。
- 澄清官方 Late 回调并非整个 Tooltip 的最终末尾；不再把“来源位于全部说明之后”当成保证。
- 加入可离线校验的 JSON 包与可独立编译的 DLL 示例，并接入标准构建入口。
- 开发包新增 `New-EZapiMod.ps1` 中英起步生成器，提供 Native/Extended 选项；`Find-EZapiApi.ps1` 可离线查询任务、完整重载签名和错误索引。两者不安装、不发物品、不保存。
- 修正关联指南的字段语义、低层工厂与声明式物品语言刷新边界，以及把历史0.1.72语言验收写成当前结果的旧文案。

新增 JSON 示例通过现有真实校验器；DLL 示例及两种风格的生成工程编译通过。生成器的 JSON/DLL × Native/Extended 四种组合通过 Windows PowerShell 5.1 检查，并核对默认选择、已有目录保护、引号/花括号/占位符文字及任务搜索。文档版本、链接与开发包边界另行检查。

本次未启动游戏；新 Tooltip 示例尚未完成实机视觉验收。59组离线框架回归与25项CLI检查属于相同运行DLL的既有证据；当前全框架实机和保存重载仍未完成。preview.1 的王尔德局部 UI 证据不扩展到本次新示例。统一状态见[release-status.json](../release-status.json)。

This is a documentation/SDK-tool revision with the identical 0.1.74 runtime DLL. It adds optional native/extended Tooltip recipes, bilingual guides, machine indexes, validated JSON and compiled DLL examples, a bilingual starter generator and offline API search. Native style explicitly disables attribution and uses native description/flavor fields. Late does not guarantee the final line. Existing Mod defaults remain compatible. New examples have no native visual or save/reload acceptance; previously recorded framework checks remain scoped to their original evidence.
