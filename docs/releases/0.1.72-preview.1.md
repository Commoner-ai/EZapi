# EZapi 0.1.72-preview.1

两个包：**game**给玩家，**developer**给Mod作者和AI。游戏包仅安装一个EZapi.dll；开发包使用同一DLL，提供可选调试配置、校验器、源码、指南、索引和样例。调试不是额外玩家依赖。

Two assets: **game** for players, **developer** for authors/AI. Both use the same single runtime DLL. Tooling DLLs are offline dependencies, not game Mods.

- Developer panel defaults off. Missing/invalid settings never activate tools. Public developer mode has inspection and explicit item generation; regression fixtures require a second explicit opt-in.
- Player installation excludes samples and EZapi.TestTools.dll. Enable/disable scripts back up settings; runtime installation preserves saves and content.
- Developer package includes `developer-tools/automation/Enter-EZapiTestStore.ps1`, guarded input, batch regression and localization helpers, plus English/Chinese instructions. Entry requires an explicit test slot and developer opt-in; no extra game DLL is needed for basic entry.
- Independent APIs cover registration, items, inventory, liquids/power, machines/recipes, dialogue/phone/suppliers, lifecycle, run/item data, transactions, requirements and localization.
- Language follows the game locale; additional CSV locales retained. Chinese/English are priority verification targets.
- Framework 0.1.72, JSON protocol 0.1; baseline Probably Stolen Demo 050REV5-L / MelonLoader IL2CPP .NET6. Validator uses .NET8.

This is a **prerelease**. Developer-options changes produce a new DLL hash. Build/offline/package checks apply to this release. Historical 415 en/zh, 18 native-save, 27 cold-load and 37 independent-disk checks apply only to the prior recorded hash 4238A189…. No exact-binary native pass is inherited.

Future persistent visitor scheduling, broader third-party combinations and final usability/publication audit remain outstanding. Starting identity registration is a mapping API, not a complete custom-start editor. The overall development goal is not marked complete.
