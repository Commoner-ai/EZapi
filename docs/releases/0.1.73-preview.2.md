# EZapi 0.1.73-preview.2 — MIT 开源 / Open source

当前框架、离线校验器、59 组源代码链接测试、构建脚本和索引工具按 MIT 许可证公开到 https://github.com/Commoner-ai/EZapi 。源码与两个二进制安装包分开获取，旧私有仓库的提交历史未迁入。游戏程序集、私人日志、存档和凭据不分发。

程序集仍为 0.1.73，运行 DLL 与 preview.1 相同；本次只整理源码发布、许可、构建入口与文档。游戏包仍只安装一份 Mods/EZapi.dll，调试默认关闭。开发包包含同一 DLL、XML 注释、校验器、接口索引、schema、调用示例及进入游戏脚本。

The runtime DLL is unchanged from preview.1. Source publication and packaging do not establish native gameplay correctness. This remains a prerelease: current-DLL native UI, mixed-Mod layouts and save/reload verification are still pending. Historical native reports remain scoped to their recorded DLLs. See [source build instructions](../build-from-source.en.md) for requirements and offline checks.
