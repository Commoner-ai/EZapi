# 0.1.86-preview.1 — optional description refresh / 空描述刷新修复

Local unpublished candidate, assembly 0.1.86. Public API signatures unchanged. Current verification state and hashes: [release-status.json](../release-status.json). No shared-game input or installation for this fix.

修复 `NativeItemOptions.LocalizedShortDescription: new("", "")` 在注册和工厂创建时合法，已有物品本地化刷新时却报 `EZAPI_ITEM_LOCALIZATION_REFRESH` / `readable text <=8192 required` 的不一致。空字符串被错误拒绝，并非文字过长。已注册内联文本刷新现在沿用工厂的 `ForLocale` 规则；简介与风味空串继续明确清空，缺失一侧回退另一侧，两侧均 null 时保留物品原字段。

Previously an accepted empty optional DLL description entered the generic readable-text resolver during refresh and failed its nonempty validation. Registered inline item fields now use the exact same locale/null resolution as their native factory. Names and source names still reject blanks, length limits still apply, and standalone readable-text Resolve plus JSON/CSV declaration validation retain their contracts.

新增 54 项源码链接回归，包含真实注册表→目录应用→工厂→已有物品刷新的链路、双语及其他 locale 回退、空串/单侧缺失/双侧 null、4000/4001 边界、空名称与来源拒绝、通用解析与 JSON 校验边界。原生目录、窗口、语言 getter 等边界使用替身；这些不是实机界面或保存重载验收。当前 DLL 全框架、混合 Mod 和保存重载仍待验收。
