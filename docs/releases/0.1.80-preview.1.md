# EZapi 0.1.80-preview.1

本地候选，尚未上传。新增 `ItemCatalogApi`，补足实际 Mod 订货系统遇到的“EZapi 声明快照不是原生全目录”边界。CaptureIdentifiers 复制原版及其他 Mod 的全部原生物品 ID；BeginScan/Step 分帧读取原生名称、基础价值和原图路径，逐项报告失败。未完成时不开放半份货池，读档/语言变化使扫描失效；临时对象清理失败停止整次扫描。普通调试面板提供手动目录导出入口。

Local candidate, unpublished. `ItemCatalogApi` captures actual native/other-Mod item IDs, beyond EZapi-only declaration snapshots. Explicit incremental scans read native names, base values and sprite keys, with per-item failures and load/locale invalidation. Partial pools stay unavailable; cleanup failures stop the scan. Optional developer tools provide a manual catalog export.

仅元数据能力：不检查图片像素、不接管订单/送货、不提供未来访客持久排程。工厂会执行自身代码，不保证任意第三方工厂没有副作用。保留信用点按钮、阵营声望和王尔德界面。

开始扫描先等待原生异步语言资源就绪；语言代码已变化但表仍在加载时明确拒绝开始。自动化助手按 PID 与 Unity 窗口类型定位游戏，避免聚焦或关闭同进程的 MelonLoader 控制台。
