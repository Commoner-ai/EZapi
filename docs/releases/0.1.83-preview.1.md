# 0.1.83-preview.1 — delivery receipts / 物品交付凭据

Local unpublished prerelease, assembly0.1.83, MIT. GitHub remains0.1.76-preview.1. Current-DLL native acceptance is pending; no shared-game input or installation for this candidate.

新增 `ItemReceiptApi.StampDetached/Capture` 与 `DeliveryReceiptAudit.Reconcile/CheckHandoff`。礼包和订单可以使用稳定操作编号、防重复账本与新库存扫描对账；原生交付后不再访问旧物品对象，InFlight 没找到凭据也不自动补发。框架保留调用方的物品工厂、原生接纳、支付、账本和保存职责。

Adds official item-data receipt tags, two fresh bounded run scans, exact single-item handoff audits and stable-operation recovery. A completed caller ledger prevents re-awarding sold/consumed gifts. Matching current inventory is evidence; neither an absent item nor a native return value proves delivery history. No automatic delivery, cleanup, retry, payment or save.

中英指南、结构化状态/错误/任务索引和独立调用示例一并提供。103项新检查链接真实生产源码、ItemDataApi 和开发包示例，使用明确原生边界替身，覆盖异常、重复、错物、换档、限额与原生销毁旧对象。构建入口共有65组离线套件、25项CLI进程检查和9个独立DLL消费方；实际执行状态及DLL哈希以 [release-status.json](../release-status.json) 为准。

The single player DLL and binary SDK remain separate packages. The SDK includes XML, validator, AI indexes, guides, consumer examples, automation and authorized art references. Framework source is obtained separately from the public repository. Original artwork retains separate rights.
