# 0.1.87-preview.1 / locale compatibility

当前预发布版，通过 GitHub Releases 分发。当前 DLL 尚未完成实机验收；准确状态以 [release-status.json](../release-status.json) 为准。

修复：生成的 `Assembly-CSharp.dll` 与开发机 SHA 不同时，旧版在调用语言 getter 前就返回英文；消费方文字和物品名称/说明会一起回退。0.1.87 在初始化后的游戏主线程核对实际 `public static string LocHelper.GetCurrentLocaleCode()`，验证返回的 locale，不再以整份包装 DLL 的摘要决定语言是否可读。只缓存成功匹配的方法绑定，临时读取失败后可以在下次展示恢复。

已有物品的显示/容器重开本地化钩子也移除该摘要门槛，继续由 `NativeHookGroup` 检查准确签名、原生可执行入口及补丁所有者。刷新仅触及 Applied 的 EZapi 物品声明；玩家自定义名称、ID 和标签保持原有保护。0.1.86 对空简介的修复保留。

公开 API 签名不变。消费 Mod 无需因本修复重新编译；如果消费方另有自己的 SHA 门槛，仍需由该 Mod 修复。其他 EZapi 功能的独立构建门控未在本次调整。

离线证据：67 组套件、25 项校验器进程检查；其中语言读取 46 项、工厂到真实语言解析和刷新 155 项、物品本地化 48 项。原生 getter、目录、Harmony 和窗口边界在离线套件中由替身提供；这些结果不证明目标玩家机器、真实语言切换或原生存档重载已经通过。本次修复验证未操作游戏；后续本机安装不构成实机验收。

The whole generated wrapper DLL SHA no longer gates locale reads or existing-item localization hooks. Exact API/thread/value checks and native hook validation remain. Public API signatures are unchanged; independent consumer SHA gates need their own fix. All evidence above is offline; current-DLL native acceptance remains pending.
