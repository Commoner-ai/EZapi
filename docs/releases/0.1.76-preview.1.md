# EZapi 0.1.76-preview.1 — 原生 UI 积木与 AI 布局预览

- 公开原生 Row、Column、Frame、Center、Inset、Section、Label、Button、Spacer 积木，支持上下/左右居中、统一间隔、字号、换行和原生语言字体。
- 严格 JSON 预览支持电脑、熔炉和养鱼机布局模板；修改后点击重载，无需重编 DLL。无文件时默认显示内嵌电脑模板。
- 导出实际控件坐标和字体所需尺寸；识别文字溢出。已有 Mod 窗口可只读 InspectWindow。预览按钮禁用、空库存锁定，关闭/读档/离开场景时清理。
- 双语开发面板与常用诊断、一次性中英测试的显式存档槽/周目绑定。普通玩家不加载开发面板；普通开发工具与回归夹具分开启用。
- 开发包补齐 schema、AI 索引、独立 DLL 编译示例和 Set-EZapiUiPreview.ps1，并保留进入游戏脚本。

本版运行 DLL 已变更。验证范围与哈希统一见 [release-status.json](../release-status.json)。60 组离线套件、25 项独立 CLI 检查和局部原生 UI/中英检查分别记录，不代表全框架、任意 Mod 组合、机器功能或当前 DLL 保存重载验收。

Native UI components and reloadable JSON preview use actual game controls and locale fonts. AI can inspect expected/actual boxes and font overflow rather than estimate layout by character counts. Three templates, bilingual docs, schema, task index, independent DLL caller and a staging tool are included. Buttons are inert and empty inventories locked in preview. Existing windows can be inspected read only. Scope and exact hash are recorded in release-status.json; full gameplay, mixed-Mod and current-DLL save/reload acceptance remain pending.

本DLL中英批量原生检查 **421/0**；551份存档文件在退出游戏后保持字节一致。测试进程还载入现有 DeepSpace Mod 0.3.7，但不据此保证任意Mod组合。原始私人日志/存档不公开；聚合范围见统一状态。
