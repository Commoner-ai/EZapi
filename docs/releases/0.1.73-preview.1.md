# EZapi 0.1.73-preview.1

> 历史发布说明：本版发布时为闭源；当前源码自 [0.1.73-preview.2](0.1.73-preview.2.md) 起按 MIT 公开。

新增 `DepartureApi`：把用户搜打撤项目的自适应离店地点按钮封装为独立框架服务。作者提供ID、文字和回调即可加入原生地图；支持动态条件、语言、稳定顺序、占位避让和无空位隐藏。原版按钮及其他Mod布局只读观察，不移动。按钮随地图、存档代次和场景清理，旧回调失效。

Destination travel, visit consumption, inventory synchronization and saving remain the caller's responsibility. The native adapter adds no Harmony patch and has no Forge/DeepSpace DLL dependency. Unknown game builds disable native attachment.

按用户要求，框架实现保持私有。源码仓库保持私有；此公开仓库只分发二进制、文档与调用示例。两个分发包均不含框架实现、内部测试或构建工程。开发包保留同一份DLL、XML注释、校验器二进制、API/任务/错误索引、文档、调用方示例及自动进入游戏工具。调试默认关闭，回归夹具需第二次明确启用，不增加玩家DLL依赖。

This is a prerelease. Source-linked departure registration/callback/layout tests pass124 checks. Direct game-method references and reachable Unity wrappers have been statically checked; these do not prove native UI behavior. New-binary native tests, mixed-Mod layout combinations and save/reload behavior remain unverified. No game was launched for this change. Historical native reports retain their recorded versions and hashes.
