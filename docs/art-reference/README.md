# Original item art reference / 原版物品美术参考

需要贴近原版画风时，先读[中文使用指南](../item-art.zh-CN.md)；English: [usage guide](../item-art.en.md).

- `originals/`: 96张原始尺寸透明PNG / 96 original-resolution RGBA PNGs.
- `enlarged-4x/`: 对应4倍最近邻透明单图 / matching 4x nearest-neighbor PNGs.
- `boards/`: 8张分类图，每类12张 / eight category boards with 12 examples each.
- [总览 / overview](00-overview.png), [常用色 / measured palettes](09-palette-reference.png).
- [中文提示词](AI-PROMPT.zh-CN.txt), [English prompt](AI-PROMPT.en.txt).
- [逐图索引 / asset index](art-reference.index.json), [文件核验 / checks](verification.json).

分类图和放大图可交给AI作为视觉参考；原图用于核对逻辑尺寸与像素细节。棋盘格、标签不属于物品。液体类仅含填充叠层，不含完整容器外壳。源Sprite名不是物品注册ID。

These are extracted original game examples, not newly generated artwork. Original artwork remains the property of its respective owners and is excluded from EZapi's MIT license. See [NOTICE](NOTICE.md). The reference set does not grant a separate artwork reuse or redistribution license.
