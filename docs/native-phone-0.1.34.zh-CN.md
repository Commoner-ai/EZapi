# EZapi 0.1.34 原生电话验收

本版提供独立的 `PhoneApi.Register/Unregister/Snapshot/IsAvailable/GetRuntimeStatus` 和 PhoneContact、PhoneContext、PhoneContactView。联系人进入游戏原生通讯录，通过原生拨号建立通话，使用不可变 DialogueScript。用法见 [电话指南](phone.zh-CN.md) 和 `../src/EZapi.Sample/PhoneExamples.cs`。EZapi 不引用、加载、转发或分发 Forge。

电话和店铺对话共用 NativeDialogueGraph 的脚本建图、分页、资源所有权和引用屏障；电话使用 DialoguePhoneUIManager，店铺使用 DialogUIManager，各自持有原生实例、选择许可、通话身份和释放状态。没有清空共享按钮、字典或原版联系人。原生文字结束不会自行挂断电话；本版在精确的原生选择许可内同步调用 OnPhoneDialogEnd，然后在选择栈返回后释放自身图，不留下可能误挂下一通电话的延时任务。
