# EZapi 0.1.33 原生对话验收

本版完成独立的 `DialogueApi.Create/Open/Close/IsAvailable/GetRuntimeStatus`，以及 DialogueContext、DialogueChoice、DialogueDefinition、DialogueScript。用法与限制见 [对话指南](../dialogue.zh-CN.md)，可编译示例为 `../src/EZapi.Sample/DialogueExamples.cs`。注册不可变托管脚本和展示原生实例分开；确认业务仍由作者处理。框架不引用、加载或分发 Forge。

截图中的调试按钮重叠已修复：对话检查、看对话、关对话移至独立一行，物品详情下移，面板增加高度。启动对话检查或展示对话后自动收起面板，避免遮挡原生按钮。最终截图 `verification/native/verified/fixed-layout.png` 已目视核对。

最终新进程仅加载 EZapi.dll，测试档 532 集中运行 **15 组 921 项，通过 921，失败 0**：对话 42、阅读 29、存档回读 9、熔炉 115、外电 82、终端 84、自动化 119、注册 42、材料 109、配方 118、事务 52、布局 46、工厂 48、模块 14、原生物品 12。逐项诊断、输入计划、截图和日志在 `verification/native/verified/`。

对话专项实读原生说话人和正文 TMP，走真实选择按钮、PLAYER 过渡、预览返回、第二页预览返回、前后翻页、确认结果、稍后离开和关闭流程。作者回调嵌套 Invoke、直接 Invoke 旧委托、确认后重放均不能重复执行业务；异常显示 FailureText，故意失败的作者回调只执行一次。低优先级原生外部请求被拒后，自有图继续有效且模式归还正确；外部成功接管后，旧回调失效。外部 next 链引用旧图时保留资源，脱离后仅释放自有令牌。

额外以鼠标实际执行：下一页 → 第二项预览 → 返回第二页 → 再次预览 → 确认 → 离开。截图显示 `已确认 choice1；执行次数：1`，离开后临时节点和物品均清零。随后先打开暂停菜单，再打开对话并点击返回主菜单；菜单诊断中旧身份失效、回调次数 0、临时资源 0。重载同一测试档后 Epoch 增加，原 14 组回归全部通过。

原生 SelectChoice 在作者回调结束后会再次读取当前节点的选项；在这个调用栈内立即替换对话会让游戏读取错误节点。本版仅在自有选择调用栈内拒绝外部 StartDialogue，返回 false；调用方可在下一帧显式请求，不自动排队或重放。栈外直接接管保留原生优先级规则。展示期间租用独白模式，以支持无实体顾客的原生推进；正常结束、关闭、失效和外部接管均归还本次设置的模式。拒绝的外部请求恢复原展示模式。

离线 **18 套 4,923 项通过，0 失败**。对话定义/执行/分页 1,436 项分别在 .NET 6.0.36 和 .NET 8.0.31 运行，重复运行不重复计数；覆盖容量 3..128、最多 128 选项、不可变复制、可达性、来源页返回、异常、身份失效和单次确认。新增适配层 63 项直接链接发行版 Dialogue.cs，只有游戏包装类型、Harmony 边界和原生排程由确定性替身提供，覆盖外部拒绝/接管、原生拒关闭、引用屏障、读档失效、释放异常和重入。替身证据不代替上述实机证据。
